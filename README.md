# SecureClock

**Security Workforce Attendance and Monitoring Application**

## About the Project

SecureClock is a workforce attendance and monitoring application designed for security companies to manage employee attendance, improve accountability and support daily workforce operations.

The application is being developed to help security managers and supervisors monitor staff attendance and verify clock-in and clock-out activities.

## Key Features

- Employee clock-in and clock-out.
- Location-based attendance verification.
- Selfie-based attendance evidence.
- QR code scanning.
- Geofence-based attendance controls.
- Workforce attendance monitoring.
- Mobile-friendly interface.

## Technology Stack

- HTML
- CSS
- JavaScript
- Base44 backend and database
- AI-assisted development
- API integration

## Project Status

**Currently in development.**

SecureClock is being developed as a practical workforce management solution for the security industry.
